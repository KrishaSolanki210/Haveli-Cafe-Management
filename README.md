# Haveli Cafe Management System ☕

A full-stack MERN Cafe Management System developed as a B.Sc IT project.

## Features

- User Authentication (JWT + OTP)
- Digital Menu
- Cart & Checkout
- Table Booking
- Order Management
- Admin Dashboard
- Razorpay Payment Integration

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
